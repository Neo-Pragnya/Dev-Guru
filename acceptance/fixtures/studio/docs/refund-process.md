# Refunding an order

How a refund moves through the shop.

1. Customer: Asks for a refund on an order.
2. Support: Checks the order was paid and is inside the refund window.
3. Support: Approves the refund or explains why it can't be given.
4. Finance: Sends the money back to the original payment method.
5. Customer: Receives the refund and a receipt.
